# Glossary

Terms used across the BasaChai specs.

Version 1.0 · 13 October 2026

| Term | Meaning |
| --- | --- |
| Advance (অগ্রিম) | Money paid once when moving in, usually one or two months' rent. May be "not specified". |
| Service charge (সার্ভিস চার্জ) | Monthly building charge for shared costs such as guard, lift and cleaning |
| Monthly total (মাসে মোট) | Rent + service charge + every monthly cost with a known amount |
| One-time costs | Advance and deposits, shown separately and never in the monthly total |
| Semi-pucca house (আধাপাকা বাড়ি) | A house with brick or concrete walls and floor and a tin roof |
| Studio | A home with 0 bedrooms in the data model |
| Live | A published listing, visible in public search |
| Reconfirm | The owner confirming a Live listing is still available, which keeps it live for 30 more days |
| Renew | Putting an Expired listing back to Live, with a fresh 30 days |
| Freshness | How recently a listing was confirmed, shown as "confirmed N days ago" |
| Read-time expiry | Treating a Live listing as Expired as soon as its 30 days pass, without a background job |
| Hide | A moderator removing a Live listing from search without changing its status |
| Reveal | Showing an owner's phone number after the tenant taps "Show number" |
| Pilot areas | The five Dhamrai areas covered at launch |
| Short ID | A short public identifier used in listing URLs instead of the database ID |
